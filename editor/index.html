StS2 perk tree editor

Open the folder of your perk-tree repo (the one that contains data/perks.json). The editor reads the perk list and the five trees from there and saves every change back to the same files, so git sees them.

Works in Chrome and Edge. Your browser asks once per session for permission to edit the folder.
